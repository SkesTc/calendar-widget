# 隱私權政策 — 行事曆小工具

最後更新：2026 年 10 月

「行事曆小工具」（以下稱「本 App」）重視你的隱私。本政策說明本 App 如何處理你的資料。

## 我們讀取的資料

- **日曆**：你授權「日曆」權限後，本 App 會讀取手機系統中已同步的日曆資料（例如 Google 日曆的行程標題、時間、地點、顏色、日曆名稱），用來顯示在桌面小工具上。
- **Google Tasks（選用）**：只有在你按下「連結 Google Tasks」並同意後，本 App 才會透過 Google Tasks API 讀取你未完成的待辦（標題、到期日、所屬清單），並在你於小工具上勾選時，把該待辦標示為完成。

## 資料如何使用與儲存

- 日曆資料 **只在你的手機上** 讀取與顯示，不會上傳到任何伺服器，也不會分享給任何第三方。
- Google Tasks 的資料只在你的手機與 Google 之間直接傳輸（加密的 HTTPS），並快取在手機上供小工具顯示；不會傳送到開發者或任何其他伺服器。
- 本 App 不會修改或刪除你的日曆內容。新增或檢視行程時，是開啟你手機上的日曆 App 來操作。
- 本 App 只會在手機上儲存你對每個小工具的設定（例如主題、要顯示的日曆）與待辦快取，解除安裝或取消連結 Google Tasks 後就會刪除。
- 本 App 使用及傳輸從 Google API 取得的資料，遵守 [Google API 服務使用者資料政策](https://developers.google.com/terms/api-services-user-data-policy)，包括「有限使用」的規定：只用於在小工具上顯示與完成你的待辦。

## 我們不做的事

- 不收集個人資料，不使用分析或追蹤工具。
- 沒有廣告。
- 只有連結 Google Tasks 時才會連網，而且只連到 Google。

## 權限

| 權限 | 用途 |
|---|---|
| 日曆（讀取） | 在小工具上顯示你的行程 |
| 開機完成通知 | 重新開機後，繼續在午夜自動更新日期 |
| 網路 | 只用於與 Google Tasks 同步（選用功能） |

你可以隨時在 App 首頁「取消連結」Google Tasks，或到 <https://myaccount.google.com/permissions> 撤銷本 App 的存取權。

你隨時可以在手機的「設定 → 應用程式 → 行事曆小工具 → 權限」關閉日曆權限。

## 兒童隱私

本 App 不會收集任何人的個人資料，包括兒童。
