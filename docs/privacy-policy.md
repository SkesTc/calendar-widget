# 隱私權政策 — 行事曆小工具

最後更新：2026 年 10 月

「行事曆小工具」（以下稱「本 App」）重視你的隱私。本政策說明本 App 如何處理你的資料。

## 我們讀取的資料

本 App 在你授權「日曆」權限後，會讀取手機系統中已同步的日曆資料（例如 Google 日曆的行程標題、時間、地點、顏色、日曆名稱），用來顯示在桌面小工具上。

## 資料如何使用與儲存

- 日曆資料 **只在你的手機上** 讀取與顯示，不會上傳到任何伺服器，也不會分享給任何第三方。
- 本 App 不會修改或刪除你的日曆內容。新增或檢視行程時，是開啟你手機上的日曆 App 來操作。
- 本 App 只會在手機上儲存你對每個小工具的設定（例如主題、要顯示的日曆）、最近搜尋的關鍵字（最多 8 個，可隨時清除）、你選擇隱藏的長期行程與學期開學日，這些都不會離開手機，解除安裝後就會全部刪除。
- 搜尋行程是在手機上查詢系統的日曆資料，關鍵字不會傳送到任何地方。

## 天氣與空氣品質（選用）

- 預設關閉。開啟後，本 App 約每小時連網查詢一次：
  - 天氣：向 [Open-Meteo](https://open-meteo.com/) 送出查詢座標。
  - 空氣品質：依你的選擇，向 Open-Meteo 送出座標，或用你自己申請的 API 金鑰向[環境部資料開放平臺](https://data.moenv.gov.tw/)下載全台測站資料（不送出座標，最近的測站在手機上挑選）。
- 查詢座標是：
  - 選「自訂縣市」時：該縣市政府所在地的固定座標。
  - 選「跟隨目前位置」時：手機的**大概位置**（需要你允許「位置」權限）。位置只在開啟本 App 或天氣詳細內容時更新，背景時使用手機最後記得的位置；本 App **不要求背景位置權限**。
- 位置與 API 金鑰只存在手機上，除了上述查詢外不會傳送到任何地方，也不會送出任何日曆內容或個人資料。
- 和任何網路連線一樣，對方伺服器會看到手機的 IP 位址；其處理方式請見各服務的隱私權政策。
- 選「不顯示」即停止連網。

## 我們不做的事

- 不收集個人資料，不使用分析或追蹤工具。
- 沒有廣告。
- 除了你自己開啟的天氣功能外，不需要網路連線。

## 權限

| 權限 | 用途 |
|---|---|
| 日曆（讀取） | 在小工具上顯示你的行程 |
| 開機完成通知 | 重新開機後，繼續在午夜自動更新日期 |
| 網路 | 只用於你開啟的天氣與空氣品質 |
| 位置（大概位置） | 只在天氣選「跟隨目前位置」時要求，用來查詢所在地的天氣 |

你隨時可以在手機的「設定 → 應用程式 → 行事曆小工具 → 權限」關閉日曆權限。

## 兒童隱私

本 App 不會收集任何人的個人資料，包括兒童。
