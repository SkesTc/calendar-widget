# 實機相容性測試清單

各家手機的桌面（Launcher）與省電機制差異很大，上架前請至少在下列每一類各測一支。

## 測試機型

| 類別 | 代表機型／系統 | 重點 |
|---|---|---|
| Pixel / 原生 Android 12+ | Pixel，Android 15／16 | 動態取色、系統圓角、預覽、設定可略過 |
| Samsung One UI | Galaxy A／S 系列，One UI 6／7 | 圓角、深色模式、「睡眠中的應用程式」 |
| 小米 HyperOS / MIUI | Redmi、POCO、Xiaomi | 自啟動、省電策略、桌面縮放 |
| OPPO / realme / OnePlus（ColorOS） | 任一 | 背景活動限制 |
| Android 8～11 | 任一舊機或模擬器 | 沒有動態取色、沒有圓角、新增時一定會開設定頁 |

## 每支手機都要測

### 新增與設定
- [ ] 從桌面的小工具清單可以看到五種 widget，Android 12+ 有預覽畫面（不是只有 App 圖示）
- [ ] 新增時跳出設定頁（Android 12+ 可以略過）；按返回鍵取消時，widget 不會留在桌面
- [ ] 從 App 首頁按「加入桌面小工具」也能新增
- [ ] 長按 widget →「編輯小工具」（各家名稱不同）可以改設定，改完 widget 立刻更新
- [ ] 調整大小：行程清單 2×2 只顯示下一個行程；月曆縮小時字變小、不重疊；時間軸可縮到 3×2
- [ ] 「下一個行程」放成 2×1 時文字不被切掉；拉高到 2 格時多顯示地點
- [ ] 「一週」4×2 是 7 欄，拉高後每欄顯示更多；放不下時出現「+N」
- [ ] 「一週」拉到 4×4 以上變成每天一列，行程顯示時間與完整標題，下方沒有大片空白
- [ ] 學校行事曆的「115學年度…」「115年…」前綴有被拿掉

### 外觀
- [ ] 6 個主題（含自訂顏色）× 淺色／深色模式，文字都看得清楚
- [ ] 毛玻璃在淺色、深色桌布上都好看
- [ ] 圓角選「系統」時，和桌面上其他小工具（例如時鐘）一樣圓
- [ ] 背景不透明度 0% 時文字仍可閱讀
- [ ] 切換系統深色模式後，widget 跟著換色（Android 11 以下可能要等下次更新）
- [ ] 換桌布後 Material You 主題跟著變色

### 資料與更新
- [ ] 在 Google 日曆新增／修改／刪除行程，1 分鐘內 widget 更新
- [ ] 過午夜後日期與「今天」標示正確（隔天早上解鎖後看）
- [ ] 時間軸：行程開始時變成「進行中」，結束後變淡
- [ ] 下一個行程：行程開始時變成「進行中 · 到 …」，結束後換成下一個
- [ ] 重新開機後，以上更新仍然正常
- [ ] 月曆切換月份、回到本月、點日期開啟 Google 日曆
- [ ] 平板或摺疊機展開：月曆拉寬後，行程出現在月曆右邊
- [ ] 月曆拉到 4×5 以上：下方出現當天行程；點其他日期會切換並標示；點行程開啟該事件；換月份後選取清除
- [ ] 點事件開啟 Google 日曆的該事件；`+` 開啟新增事件

### 隱藏長期行程
- [ ] 首頁「長期行程」→「管理」列出跨 3 天以上的行程（例如學期、寒暑假）
- [ ] 打開「隱藏」後，所有 widget 上都不再顯示該行程；關掉後恢復
- [ ] 首頁卡片的「已隱藏 N 個」回到首頁時有更新
- [ ] Google 日曆裡的行程沒有被修改

### 第二輪回饋
- [ ] 「長期行程」清單裡有每天／每週重複的行程，顯示「重複 N 次」，隱藏後每一次都不見
- [ ] 小工具設定的日曆依帳號分組；取消勾選帳號 → 該帳號所有日曆隱藏；只勾部分時帳號顯示「—」
- [ ] 在 widget 按 `+` 新增行程、存檔回到桌面 → 新行程馬上出現
- [ ] 點行程進去修改或刪除、回到桌面 → 馬上更新
- [ ] 今天已經結束的行程還在，但色條是灰的、文字比較淡；行程結束的那一刻會自動變淡

### 農曆與假日
- [ ] 月曆（4×4 以上）顯示農曆小字、節氣、傳統節日
- [ ] 訂閱「台灣的節慶假日」後：放假日紅字、補班日標「補班」且不是紅字、紀念日（例如母親節）不是紅字
- [ ] 關閉「顯示農曆」後小字消失，但假日名稱仍顯示

### 第三輪：全面優化
- [ ] 新安裝第一次開 App：出現三步引導（授權 → 加小工具 → 假日）；授權後自動跳下一步；「略過」後不再出現
- [ ] 首頁今天卡片列出今天的行程，點一下開啟編輯；改完回到首頁有更新
- [ ] 搜尋：「即將到來／本週／本月」與日曆篩選正確；最近搜尋保留 8 筆、可以清除
- [ ] 小工具設定 →「進階」只勾部分標題列按鈕，桌面上只出現勾選的；按鈕放不下時出現「⋯」
- [ ] 「套用到所有小工具」後，每個小工具都換成同樣的設定
- [ ] 一週小工具選「週一開始」「週日開始」後，第一欄正確
- [ ] 下一個行程顯示倒數，接近開始時每 5 分鐘更新
- [ ] 晚上今天行程都結束後，時間軸出現「明天」的行程
- [ ] 首頁「學期週次」設定開學日後，月曆左邊出現週次，其他小工具日期下方出現「第N週」；選「不顯示」後消失
- [ ] 放假日的日期有底線（月曆、一週）

### 權限
- [ ] 第一次開啟 App 前就新增 widget：顯示「點此授權讀取日曆」，點了會開 App
- [ ] 拒絕權限後再到系統設定允許，widget 恢復正常

## 已知限制（不是 bug）
- 毛玻璃是半透明漸層模擬，不是真的模糊（Android widget 不支援）。
- Material You 主題的背景調成半透明時，換桌布後要等下次更新（最多 30 分鐘）才會換色。
- 小米、vivo 等手機如果沒有允許「自啟動」，午夜換日與時間軸可能要等打開 App 才更新；App 首頁的「小工具沒有自動更新？」有各品牌的設定步驟。
